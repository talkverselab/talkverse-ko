# 한국어 절벽구간 (2026-11-03, 일본어앱과 같은 방식)

- 말뭉치: 한국 제작 영화·드라마 대사 4,268편(영화 430 · 드라마 회차 3,838), 2,322만 토큰. 공개 저장소라 제공처 이름은 적지 않는다.
- 단위: 형태소(kiwi). 조사·어미도 한 단어로 세어 분자·분모에 넣고(일본어 조사·조동사와 같게), 용언은 기본형(어간+다), 기호·숫자·외국어는 뺀다.
- frequency = 토큰 수 ÷ 전체 토큰(가중 없음). 2,500위 최대 누적 = **91.99%**.
- 구간(최대치 비례 55/60/70/80 ÷ 80): **R1 = 130위(63.3%) · R2 = 199위(69.0%) · R3 = 547위(80.5%) · R4 = 2,500위(92.0%)**.
- 파일: `lang_ko_top2500.csv`(rank,word,pos,frequency,cum_pct,region), `ko_cliff_summary.json`. 재현: `tools/corpus/cliff_ko.py <말뭉치.zip> <출력> --only <작품 번호 목록>`.
- 앱 단어장(`assets/seed/vocab.json`, 예전 어절 표)은 아직 이 값으로 바꾸지 않았다.
