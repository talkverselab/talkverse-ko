1 A: 이 팝콘 완전 맛있네. / This popcorn is so good. / 초안의 '진짜 맛있다'를 현장 감탄 '완전 맛있네'로 바꿔 더 구어체로 재작성
2 B: 그치? 반반으로 시켰어. / Right? I got the half-and-half. / '캐러멜 반, 치즈 반'을 실제 주문할 때 쓰는 '반반'으로 줄여 자연스럽게 다시 씀
3 A: 어? …손 닿았어. 미안! / Huh? …Our hands touched. Sorry! / 손 닿은 걸 바로 말하고 미안을 붙여 클리셰를 알아보게 하면서 재작성
4 B: 아니… 괜찮아. 나도 미안. / No… it's fine. Sorry too. / 말끝을 더 흐리고 당황을 살려 반전 킥을 코믹하게 키움
5 A: …하나 더 사 올까? / …Want me to get another one? / 초안의 설명을 빼고 말끝을 흐려 여백 있게 다시 씀
6 B: 아니. 이걸로 충분해. / No. This one's enough. / '하나면 돼'를 더 자연스러운 '이걸로 충분해'로 바꿔 재작성
7 A: 왜 그래? / Why though? / 짧은 '왜?'를 '왜 그래?'로 늘려 맞장구 느낌 살림
8 B: …그래야 또 닿지. / …So we can touch again. / 초안 문장을 그대로 두지 않고 여운을 더 남기도록 말끝 조정
