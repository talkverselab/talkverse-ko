2 A: 여기면 돼? 좋아. / Here is fine? Good. / 초안 "여기?"를 "여기면 돼?"로 확인 질문으로 바꿔 학습 목표 좋아를 자연스럽게 넣음.
3 B: 하나 둘 셋, 브이 해 봐. / One, two, three, try a V. / 초안 감탄과 분리된 지시를 한 문장으로 이어 "해 봐"로 구어 권유로 바꿈.
4 A: 브이? 이렇게 하면 돼? / V? Like this is okay? / 초안 짧은 확인을 "이렇게 하면 돼?"로 의문 확장해 더 실제 반응처럼 만듦.
5 B: 아니야, 볼에 이렇게 해 봐 더 귀엽게! / No, on the cheek like this, cuter! / 초안 분리 지시를 한 문장으로 묶고 "더 귀엽게!"로 킥을 세게 코믹하게 강조.
6 A: 진짜? 다들 이렇게 하는 거야? / Really? Does everyone do it like this? / 초안 "다 이렇게 해?"를 "다들 이렇게 하는 거야?"로 더 구어 질문으로 바꿈.
7 B: 응 응, 한국에선 다 브이 해. / Yeah yeah, in Korea everyone does a V. / 초안 "한국 사진은 브이야"를 "한국에선 다 브이 해"로 생활 표현으로 바꾸고 맞장구 추가.
8 A: 알겠어. 브이 해 볼게. / Got it. I'll try a V. / 초안 "알았어. 브이!"를 "알겠어. 브이 해 볼게."로 능동 의지로 바꿔 여운을 줌.
