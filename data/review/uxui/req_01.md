[KU01] 한국어 학습 앱(영어권 학습자가 한국어를 배우는 앱) UX/UI 시안 1개를 부탁합니다.

기준 앱: 같은 시리즈의 일본어 학습 앱 최신 저장소 https://github.com/talkverselab/talkverse-ja (master 최신). 특히 lib/screens/main_screen.dart · lib/screens/dialogue_screen.dart · lib/widgets/episode_play_pane.dart · lib/screens/dialogue_card_screen.dart · lib/widgets/achievement_desk.dart · docs/TWO_PANE_UX.md · data/review/uxui/sian_02.md(이 앱이 채택한 「만화책 읽기형」 시안)를 읽어 주세요. **구조(탭 4개 배우기·복습·탐색·나 / 아이패드 레일+두 칸 / 주제→편→회화 재생 / 그림 카드 / 라이트너 복습 / 성과 데스크)는 그대로 두고**, 겉모습과 경험을 **한국 느낌, 특히 K-드라마를 보는 느낌**으로 다시 설계해 주세요.

방향(제안 — 더 좋은 생각이 있으면 바꿔도 됨):
- 회화 한 편 = 드라마 한 회. 「EP.1」 회차 표시, 오프닝 타이틀 카드, 장면 스틸컷이 주인공, 대사는 드라마 자막처럼(한글 + 영어 자막 + 로마자 토글), 편 끝은 엔딩 크레딧/「다음 회 예고」 한 컷으로 다음 편을 보고 싶게.
- 주제(서바이벌·친구·사랑·생활·여행·문화·일·학업) = 드라마 「시리즈/채널」 목록처럼. 고정 인물이 계속 나오는 연속극 느낌(포장마차·편의점·한강·비 오는 날 우산·첫눈·노래방·회식 같은 K-드라마 상황).
- 학습자는 영어 사용자다. 화면 문구는 한국어/영어/일본어/중국어로 바뀌므로 영어 기준 길이에 맞출 것.
- 매일 열고 싶은 이유: 스트릭·포인트·순위 대신 "다음 회가 궁금하다" + 빈도 커버율(아는 단어로 일상 한국어의 ○○% 이해)이 조용히 오르는 것.
- 톤: 흰 바탕·남색 #0A2540·인디고 #635BFF 계열은 시리즈 공통. 한국 느낌 포인트 색 1~2개는 제안해 줄 것.
- 금지: 실존 드라마·배우·아이돌·방송사·OTT 이름과 로고, 실제 작품 장면·명대사. 분위기와 상황만.

출력(이 순서로):
1. 콘셉트 한 단락(이름 붙여서)
2. 와이어프레임 이미지 **1장** — 아이패드 가로, 왼쪽 레일 + 두 칸, 「편 재생(드라마 한 회 보기)」 화면
3. 텍스트 레이아웃(ASCII) — 홈(배우기 첫 화면) / 주제(시리즈) 목록 / 편 재생 / 편 끝(엔딩·다음 회 예고) / 폰 세로 재생
4. 색·글꼴·모서리·간격 토큰 표, 주요 컴포넌트 목록(이름·역할 한 줄씩)
5. 일본어 앱 시안 02 에서 바꾼 점 5줄 요약
