1 C: 오늘 저녁은 그냥 아무거나 먹으면 되지. / We can just eat whatever for dinner tonight. / 직접적인 「먹자」를 더 편한 구어체 「먹으면 되지」로 바꿔 자연스럽게 흘리듯 말하게 함
2 A: 아 그럼 파스타 어때요? / Oh, then how about pasta? / 「그럼」 앞에 「아」를 붙여 실제 반응하듯 말 시작을 흐리게 만듦
3 B: (속삭이며) 팀장님은 삼겹살 좋아하세요. / (whispering) The boss likes samgyeopsal. /  blunt한 「이야」를 공손하고 구체적인 「좋아하세요」로 바꿔 힌트를 더 부드럽게 전달
4 A: 진짜요? 아무거나라셨는데요. / Really? But he said anything. / 학습 목표 「진짜요?」를 넣어 모순에 대한 코믹한 당황을 더 세게 살림
5 B: 팀장님 아무거나는 삼겹살이에요. / The boss’s “anything” means samgyeopsal. / 등호식 설명을 완전한 구어체 문장으로 바꿔 킥을 더 분명하고 웃기게 만듦
6 A: 네, 이거 삼겹살 어떠세요? / Yes, how about this, samgyeopsal? / 「네 이」를 「네, 이거」로 자연스럽게 녹여 제안하는 말로 다시 씀
7 C: 오, {name} 씨 센스 좋네! / Oh, {name}, you’ve got good sense! / 감탄을 더 즉각적이고 구어적인 「좋네」로 바꿔 실제 칭찬처럼 들림
8 B: (속삭이며) 이게 바로 눈치예요. / (whispering) This is exactly nunchi. / 「야」를 공손한 「예요」로 바꾸고 「바로」를 넣어 핵심을 강조하는 한 줄로 만듦
